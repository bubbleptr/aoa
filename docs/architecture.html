内核五个原语
Inbox收事件，去重、租约、失败重试
Timerswake_me_at，到期变成事件
Worker认领一批事件 → 开一次 run → 记下结局；进程崩溃后从日志接着做
Memory指令 · 笔记 · 进度 · 已发消息
Permissions策略 · 分类器 · 审批 · 一次性许可
Outbox消息和审批请求，至多送达一次
SQLite一个文件：事件、会话、日志、决定、消息都在这里
Runtime每个 agent 选一个
第一档 pi

只有 aoa 给的工具。每次调用都经过内核：裁决、写日志、执行，崩溃后按日志重放。

审查角色由 aoa 的只读规则把关。

第二档 · 外部 harness 用它自己的工具和沙箱

它要问的审批经内核转给你，批准后记一次性许可。aoa 的工具接进去后仍是第一档。
